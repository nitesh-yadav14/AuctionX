# Security Policy

## Reporting a Vulnerability

Please report security issues **privately** using GitHub's
"Report a vulnerability" option on the repository's **Security** tab
(Security -> Advisories -> Report a vulnerability). Please do not open a
public issue for security problems.

Include as much detail as possible:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any relevant logs or screenshots

## Supported Versions

This policy covers the latest version on the `main` branch.

## Response Process

- Reports are acknowledged as soon as the maintainer is able to review them.
- Fixes are prioritised by severity.
- Once fixed, the issue is disclosed responsibly.

Thank you for helping keep the project secure.
